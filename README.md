# Aubrey's White Space

Aubrey's White Space is a Balatro content mod featuring custom Jokers, consumables, and other ideas inspired by things I'm into.

Currently adds 4 rare, 2 uncommon and 5 common jokers.

**[Aubrey's White Space mod website](https://white-space-wiki.vercel.app)**

## Requirements

- [Balatro](https://store.steampowered.com/app/2379780/Balatro/)
- [Lovely Injector](https://github.com/ethangreen-dev/lovely-injector)
- [Steamodded](https://github.com/Steamodded/smods)

Use versions compatible with your installed Balatro version and follow the official installation instructions for each dependency.

## Installation

1. Install Lovely and Steamodded.
2. Download the latest release of Aubrey's White Space from [here](https://github.com/AlperCeyhun/WhiteSpace/archive/refs/heads/main.zip).
3. Extract the mod folder into %AppData%/Balatro/Mods/.
4. Launch Balatro and check the Mods menu to verify the mod is loaded.
